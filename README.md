# TCC-PNAAT

Trabalho de Conclusão de Curso do **PNAAT** (Programa Nacional Acelerado de
Aprendizado em Tecnologia) — Intensivo Maker, com foco em IoT e Edge AI.

O projeto responde ao Cenário 8 dos problemas reais propostos pelo programa:
um **modelo preditivo de falhas em máquinas e esteiras industriais**,
construído sobre uma arquitetura de IoT.

**Status:** 🚧 Em desenvolvimento

**Stack:** [ESP-IDF](https://github.com/espressif/esp-idf) (C) — firmware
embarcado para ESP32.

**Equipe:** Levi Farias e equipe (4 integrantes) — Intensivo Maker PNAAT.
